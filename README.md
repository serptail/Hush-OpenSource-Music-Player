# Hush

Hush is a native Kotlin/Jetpack Compose music application organized as a multi-module Clean Architecture project.

## Modules

- `app`: Hilt application entry point and Compose navigation
- `core/core-model`: pure Kotlin domain models
- `core/core-common`: shared failures and dispatchers
- `core/core-database`: Room entities, DAOs, database, and mappers
- `core/core-network`: Retrofit DTOs and API contracts
- `core/core-player`: Media3 player abstraction and media-session service
- `core/core-designsystem`: Compose design-system dependency boundary
- `feature/*`: search, library, player UI, and source resolution boundaries
- `sync`: local Ktor resolution-cache service on port 8080

## Build prerequisites

- Android Studio with Android SDK 35 and Java 17 or 21
- Gradle 8.10.x or the Gradle wrapper generated by Android Studio

The current machine has Java 25/26 runtimes, which are too new for the selected Kotlin compiler. Set `JAVA_HOME` to a Java 17 or 21 installation before building.

## Commands

```powershell
.\gradlew.bat :app:assembleDebug
```

### Run the local yt-dlp backend

Use a second Android Studio terminal or PowerShell window and keep this process running while testing the app:

```powershell
$env:JAVA_HOME = "C:\Users\Yugen\.jdks\ms-21.0.12.1"
$env:YTDLP_PATH = "C:\Users\Yugen\AppData\Local\Programs\Python\Python311\Scripts\yt-dlp.exe"
.\gradlew.bat :sync:run
```

### Build and install the APK

In another terminal:

```powershell
$env:JAVA_HOME = "C:\Users\Yugen\.jdks\ms-21.0.12.1"
.\gradlew.bat :app:assembleDebug
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
```

Or open the `Hush` folder in Android Studio, select the `app` run configuration, choose your emulator, and press Run. Keep the backend terminal running separately.

### Production deployment

The terminal is only needed for local development. For real devices, deploy `sync/Dockerfile` to a small VPS, container host, or home server with a stable HTTPS domain. The container includes Java, Ktor, Python, and auto-updating yt-dlp. Then build the APK with that backend URL:

```powershell
.\gradlew.bat :app:assembleDebug -PsyncBaseUrl=https://hush-api.example.com/
```

The installed APK then calls the hosted service directly; users do not need Android Studio, Gradle, Python, yt-dlp, or a terminal. Use HTTPS in production and keep the emulator default `http://10.0.2.2:8080/` only for local development.

Search, local resolution caching, playlist creation, playlist track persistence, and player controls are wired. MusicBrainz and the Cover Art Archive require no credentials. Android yt-dlp search and audio stream extraction run inside the app; a YouTube watch-page URL is never passed to Media3 as if it were an audio stream.

Install yt-dlp on the machine running the sync service, then expose its executable to the service with `YTDLP_PATH` if it is not already on PATH:

```powershell
python -m pip install --upgrade yt-dlp
$env:YTDLP_PATH = "C:\Users\<you>\AppData\Local\Programs\Python\Python311\Scripts\yt-dlp.exe"
gradle :sync:run
```

The bundled Android yt-dlp wrapper updates its binary in-app from the stable release channel. The backend remains available for optional shared resolution caching and server deployments, but normal users do not need a server, Docker, Python, yt-dlp, or a terminal. The wrapper is GPL-3.0 licensed; preserve its license and notices when distributing Hush.

When MusicBrainz does not return an ISRC, Hush uses a deterministic `fallback:<artist>|<title>|<duration>` key for local and remote resolution caching. This prevents blank ISRCs from colliding while keeping the fallback visibly distinguishable from a real ISRC.
